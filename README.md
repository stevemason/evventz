# Evventz

Displays a list of upcoming and past events, taken from a json file.

See data.json.example for the data format.

'Title' and 'date' are mandatory fields.

If a URL is present, clicking on the event title will take you to the URL.

Adding "(?)" to the end of an event title causes it to appear with a 'tentative' badge.

Tentative events in the past will not be displayed.
